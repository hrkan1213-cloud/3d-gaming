# 🐹 햄스터 줄다리기 3D 게임

Three.js를 사용한 3D 미니게임입니다.

## 게임 방법

1. **시작 버튼**을 클릭하여 게임을 시작합니다
2. 게임이 시작되면 **컴퓨터 햄스터**가 자동으로 덩굴을 먹기 시작합니다
3. **스페이스바**를 빠르게 연타하여 플레이어 햄스터가 덩굴을 먹게 합니다
4. 덩굴을 많이 먹는 쪽으로 줄다리기가 진행됩니다
5. 덩굴을 끝까지 먹어서 승리하세요!

## 기능

- 🎮 3D 그래픽 (Three.js)
- 🐹 귀여운 햄스터 캐릭터 2마리
- 🌿 3D 덩굴 오브젝트
- ⌨️ 스페이스바 연타 게임플레이
- 🤖 자동으로 움직이는 컴퓨터 AI
- 📊 실시간 진행 상황 표시
- 🏆 승패 판정 시스템

## 실행 방법

브라우저에서 `index.html` 파일을 열면 됩니다.

## 기술 스택

- HTML5
- CSS3
- JavaScript (ES6+)
- Three.js (r128)
